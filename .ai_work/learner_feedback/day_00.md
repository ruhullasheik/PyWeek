# Day 00 — Tools

**How was the day?**
It was decent. Setup guides are OS-specific which is nice, but honestly I already had Python and Git installed from lab work. The terminal cheatsheet is handy — I'll bookmark that. First script ran without issues.

**What's good?**
- OS-specific install guides — no guessing what command works on my machine
- Terminal cheatsheet with both PowerShell and bash side by side
- Exercises are practical (path_ninja, git_story actually made me use git)
- sandbox/ folder is a nice touch — didn't clutter my working tree

**What can be improved?**
- Exercise 1 ("Hello You") asks for "nth language" but doesn't say how to know how many languages they've used before. I ended up just hardcoding "next" instead of "2nd" — the hint didn't resolve this either.
- uv is introduced but day-00 doesn't explain *why* uv over pip. I installed it but don't know when I'd use it.
- The git workflow doc is good but assumes you know how to use a fork. Some students might not have used GitHub before.

**What I struggled with:**
- Nothing really — it's all setup and basic commands. The hardest part was deciding which terminal commands to try first on the path_ninja exercise.

**What clicked easily:**
- The `sandbox/` concept. I immediately started scratching notes there.
- Running Python scripts via `py` on Windows — didn't know that existed.
- The branch-switching model makes sense after reading the git workflow doc.

**As a B.Tech student, I'd say:**
> "OK setup day done. Can we write actual Python now?"

**Confidence after this day:** High

**Time spent:** ~2.5 hours (already had most tools installed)
