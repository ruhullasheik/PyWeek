# PyWeek Course Evaluation

**Overall confidence to join a project:** Almost

**What's good (top 3):**
1. Branch-per-day model keeps each day focused — no clutter from previous days
2. Examples are runnable and tweakable — I learn more when I break things and fix them
3. The "You Know — Python" comparison tables save time for programmers coming from other languages

**What's missing (top 3):**
1. Error handling (try/except) isn't covered explicitly. I saw it mentioned in passing but no dedicated exercises.
2. Real-world examples could be stronger. Day-02's currency converter is good; day-00's first script is too trivial.
3. No testing. I saw pytest in the advanced folder on day-05 but didn't get to it. Would be better as a required exercise.

**As a B.Tech student, I'd tell my friends:**
> "Good course for learning Python syntax fast. But you'll need a testing tutorial after."

**Total time spent:** ~9 hours across 3 days

**Last words:**
Day-01 and day-02 were strong. Day-00 could be shortened for students who already have tools installed. The switch between branches is smooth once you get the hang of it. Would recommend adding error handling as a required topic — it's a basic skill that affects everything.
