# Day 06 — Object-Oriented Programming

**Estimated time**: 5–6 hours (longest day)  
**Practice required**: Yes — exercises are mandatory

## Learning Objectives

- Define classes with `class`, `__init__`, `self`
- Use inheritance and `super()`
- Write `@property` for computed/validated attributes
- Understand `@staticmethod` vs `@classmethod`
- Use `dataclasses` for simple data containers
- Explore advanced topics: decorators, generators, context managers
