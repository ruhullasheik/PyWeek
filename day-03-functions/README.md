# Day 03 — Functions

**Estimated time**: 4–5 hours  
**Practice required**: Yes — exercises are mandatory

## Learning Objectives

- Define and call functions with `def`
- Understand default args, keyword args, `*args`, `**kwargs`
- Write and use `lambda` functions
- Understand scope (LEGB rule)
- Write docstrings and run Ruff to lint your code

## Key Python Concepts

| You Know (C/Java) | Do This In Python |
|---|---|
| `int add(int a, int b)` | `def add(a, b):` |
| `void printMsg(String m)` | `def print_msg(m):` (returns `None`) |
| Function overloading | Not needed — default args + `*args` |
| `(int a, int b) -> a + b` (Java lambda) | `lambda a, b: a + b` |
| `public static` methods | No access modifiers — just functions |
