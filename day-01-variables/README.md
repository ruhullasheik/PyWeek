# Day 01 — Variables & Types

**Estimated time**: 3–5 hours  
**Practice required**: Yes — exercises are mandatory

## Learning Objectives

- Understand Python's dynamic typing model
- Use `int`, `float`, `str`, `bool` confidently
- Write f-strings and handle user input
- Understand mutability vs immutability

## Key Python Concepts (You Know These From C/Java — Here's What's Different)

| Concept | C/Java | Python |
|---|---|---|
| Variable declaration | `int x;` | `x = 5` (no type keyword) |
| Type checking | Compile-time | Runtime (`type(x)`) |
| Strings | `char*` or `String` | `str` (immutable, Unicode) |
| Boolean | `bool` / `int` | `True` / `False` (capital T/F) |
| Constants | `const int MAX = 10;` | Convention: `MAX = 10` (no enforcement) |
| null/nil | `null` / `NULL` / `None` | `None` (singleton object) |
| Increment | `x++` / `++x` | Not supported. Use `x += 1` |
| AND/OR/NOT | `&&` / `||` / `!` | `and` / `or` / `not` (keywords, not symbols) |
