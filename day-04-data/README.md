# Day 04 — Data Structures

**Estimated time**: 4–5 hours  
**Practice required**: Yes — exercises are mandatory

## Learning Objectives

- Master list comprehensions (you'll use them daily)
- Use slicing with confidence
- Choose between list, dict, set, tuple for the right job
- Use dict and set operations efficiently
- Use `collections.defaultdict` and `collections.Counter`

## Key Python Concepts

| You Know | Python Equivalent |
|---|---|
| Array | `list` (dynamic array, resizable) |
| HashMap / HashTable | `dict` |
| HashSet | `set` |
| Tuple (immutable list) | `tuple` |
| Arrays.sort() | `sorted(lst)` |
| list.length / arr.length | `len(lst)` |
