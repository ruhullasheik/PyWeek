# PyWeek

**7 days. 1 language. Zero regrets.**

A structured 7-day learning challenge to master Python and essential developer tools in one week. Designed for programmers who already know programming (C, C++, Java, etc.) but are new to Python.

## How It Works

Each day lives on its own Git branch. Switch once per day, work through the content, and by day 7 you'll ship a complete Python project.

```
git switch day-00-tools      # Day 1: environment & Git
git switch day-01-variables  # Day 2: types & I/O
git switch day-02-control    # Day 3: loops & conditionals
git switch day-03-functions  # Day 4: functions & Ruff
git switch day-04-data       # Day 5: collections
git switch day-05-modules    # Day 6: imports & packages
git switch day-06-oop        # Day 7: classes & beyond
git switch day-07-project    # Day 8: capstone project
git switch main              # Graduation hub
```

## Daily Structure

Every day branch follows the same layout:

```
day-XX-topic/
├── README.md        # Objectives, estimated time, practice expectations
├── topic/           # Primers, guided examples, exploration challenge
├── exercises/       # 3–5 progressively harder tasks
├── solutions/       # Partial hints — fill in the logic yourself
└── reflection.md    # Questions to reinforce learning
```

You are expected to **practice every day**. Exercises are non-negotiable — they're why this works in a week.

## Prerequisites

- You already know programming fundamentals (variables, loops, functions, OOP)
- You're comfortable with a terminal/command line
- Python is **not** installed? Day 0 will set you up

## Philosophy

- **Strict 7 days** — no day 8. New content goes under the relevant day.
- **Hands-on first** — guided examples, exercises, challenges. Minimal reading.
- **Tools in context** — Git, uv, Ruff are introduced when you see why they matter.

## Graduation Hub (You Are Here)

`main` is where you land after completing all 7 days:

| Section | What's Inside |
|---|---|
| `capstones/` | Harder standalone projects (CLI apps, web scrapers, REST APIs) |
| `interview/` | Python-specific interview problems & solutions |
| `tool-practice/` | Git exercises — branching, merging, conflict resolution |
| `next-steps.md` | Where to go after PyWeek |
| `template/` | The structure template used for each day |

By the end of PyWeek you should feel:  
*"I know Python. I can build, debug, and solve problems. I'm ready for interviews and real projects."*
