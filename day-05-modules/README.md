# Day 05 — Modules & Packages

**Estimated time**: 4–5 hours  
**Practice required**: Yes — exercises are mandatory

## Learning Objectives

- Import and use standard library modules
- Create your own modules and packages
- Use `uv` to install and manage third-party dependencies
- Understand `__name__ == "__main__"` idiom
- Write a CLI tool using `argparse`

## Key Python Concepts

| You Know | Python |
|---|---|
| `#include <math.h>` | `import math` or `from math import sqrt` |
| `import java.util.*` | `from collections import defaultdict` |
| JAR files / packages | PyPI packages via `uv pip install` |
| maven / gradle | `uv add` |
| `public class Main { ... }` | `if __name__ == "__main__":` |
