# Capstone Projects

Harder projects that go beyond day-07. These assume you've completed all 7 days and want a real challenge.

## Web Scraper (with `requests` + `BeautifulSoup`)

Scrape a news website and build a CLI tool that:
- Fetches headlines from multiple categories
- Caches results to avoid re-fetching
- Exports to JSON/CSV
- Can be scheduled (via cron / Task Scheduler)

## REST API with FastAPI

Build a book library API:
- CRUD endpoints for books (title, author, ISBN, status)
- SQLite database via SQLAlchemy
- Search by title/author
- JSON responses with proper status codes
- Dockerfile + docker-compose

## CLI Pomodoro Timer

A terminal-based productivity timer:
- 25 min focus, 5 min break cycles
- Desktop notifications (via `plyer` or `notify-send`)
- Session history stored in JSON
- Configurable durations

## Data Analysis Dashboard

Using pandas + matplotlib:
- Load a dataset (Kaggle, government data, etc.)
- Clean and transform
- Generate 3+ visualizations
- Export as a PDF report
