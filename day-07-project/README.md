# Day 07 — Capstone Projects

**Estimated time**: 5–8 hours (pick ONE project)  
**Practice required**: Yes — this is the final exam

## Learning Objectives

- Integrate everything from days 00–06 into a complete project
- Practice planning, structuring, and shipping Python code
- Apply tooling: Git, uv, Ruff

## How It Works

1. **Pick one project** from the `projects/` folder
2. **Read the spec** carefully
3. **Plan** before coding — sketch your classes/functions
4. **Implement** — use your own `uv venv`, commit to Git, run Ruff
5. **Polish** — error handling, user experience, code quality
6. **Reflect** — answer the questions in `reflection.md`

## Projects Available

| Project | Difficulty | Skills Tested |
|---|---|---|
| **CLI Expense Tracker** | Medium | Files/JSON, argparse, datetime, CRUD |
| **URL Shortener** | Medium | HTTP APIs (requests), JSON, random strings |
| **Markdown to HTML Converter** | Medium-Hard | Regex, string processing, OOP |
| **Todo API Client** | Medium-Hard | HTTP, json, error handling, CLI |
| **Data Analysis: Weather** | Medium | CSV, statistics, matplotlib (optional) |

Open a PR or push your project branch to your fork when done.
