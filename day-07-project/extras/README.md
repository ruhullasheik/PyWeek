# Extras

Additional challenges if you finish your project early.

## Mini Challenges

1. **Implement `wc` in Python** — recreate the Unix word count tool
   - `python wc.py file.txt` → lines, words, characters

2. **TOTP Token Generator** — generate time-based one-time passwords (like Google Authenticator)
   - Use `hmac` and `time` modules

3. **Port Scanner** — scan open ports on a remote host
   - `python scan.py example.com --ports 1-1000`

4. **Diff Tool** — compare two files line by line and show differences
   - `python diff.py file1.txt file2.txt`

## Interview-Style Problems

1. **Two Sum** — find two indices that sum to a target
2. **Valid Parentheses** — check if brackets are balanced
3. **LRU Cache** — implement with O(1) get/put
4. **Merge Intervals** — merge overlapping intervals
5. **Word Ladder** — shortest transformation path
