# Next Steps

You finished PyWeek. Now what?

## Level Up Your Python

| Topic | Why | Resource |
|---|---|---|
| **Type Hints** | Production code uses them. Makes your code self-documenting. | `mypy` docs |
| **Pytest** | Testing isn't optional. Write tests for your capstone. | pytest docs |
| **Async/Await** | I/O-bound tasks (web scraping, APIs) | `asyncio` docs |
| **FastAPI** | Build REST APIs in minutes. | fastapi.tiangolo.com |
| **Pandas** | Data analysis at scale. | pandas.pydata.org |
| **Click / Typer** | Better CLI tools than argparse. | typer.tiangolo.com |

## Contribute to Open Source

- Find a small Python project on GitHub
- Fix a documentation typo first (low stakes)
- Then fix a `good first issue`

## Interview Prep

The `interview/` folder has Python-specific problems. Beyond that:

- **LeetCode** in Python (use comprehension, generators, etc.)
- **System Design** (not language-specific)
- **Behavioral** (STAR method)

## Build Something

Pick one and ship it:

- CLI tool you personally need
- Web scraper for something useful
- Simple web app with FastAPI + HTMX
- Data analysis of a public dataset
- Automation script for your daily workflow
